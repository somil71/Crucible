Jump-on-Idle Discrete Time

Time never flows via sleep calls. When nodes wait for an election timeout, Crucible jumps virtual clock directly to the next scheduled timer, achieving 240,000× speedup without CPU spinning.

Bit-Exact Seeded Replay

All non-determinism (thread scheduling, network re-ordering, entropy, clock reads) is captured in a single 64-bit seed. A failure discovered once will replay identically on any machine forever.

Automated Delta-Debugging

Crucible bisects 1,000,000-event execution traces down to the minimal 3 to 5 fault events required to trigger the bug, generating an upstream bug report ready for submission.

CLI & GitHub Actions Automation

Run campaigns headlessly in your CI pipeline to catch race conditions and split-brain bugs on every pull request.

1. Install Crucible CLI
cargo install --path crates/crucible-cli
2. Run Fuzzing Campaign
# Run 1,000,000 virtual steps across 20 groups with 100 nodes crucible campaign --nodes 100 --steps 1000000 --seed 0xDEADBEEF --output bundle.json
3. GitHub Actions CI Pipeline (.github/workflows/crucible.yml)
name: Crucible Distributed Invariant Audit on: [push, pull_request] jobs: audit: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: dtolnay/rust-toolchain@stable - name: Run Deterministic Campaign run: cargo run -p crucible-cli -- campaign --steps 500000 --fail-fast
