Crucible CLI Setup & Operator Guide

Install Crucible locally or integrate it into your continuous integration (CI) pipeline.

1. Installation

# Install via Cargo directly: cargo install --path crates/crucible-cli # Verify installation: crucible --version

2. Run a 100-Node Bug Zoo Campaign

Executes 100-node simulation, delta-debugs schedule to ≤ 5 events, and packages signed advisory:

crucible campaign --seed 1337 --out UPSTREAM_BUG_REPORT.md

3. Independently Verify an Evidence Bundle (CLM-004)

crucible verify --bundle CRUCIBLE-BUG-2026-001.json --replay

4. Run Multi-Iteration Determinism Audit

crucible audit --runs 1000 --seed 42
