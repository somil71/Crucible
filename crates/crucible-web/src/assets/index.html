Crucible CLI Setup & Operator Guide

Install Crucible locally or embed it directly into your GitHub Actions / GitLab CI pipelines.

1. Installation

bash
# Install via Cargo directly from source: cargo install --path crates/crucible-cli # Verify version and environment: crucible --version

2. Run a 100-Node Bug Zoo Campaign

bash
crucible campaign --seed 1337 --out UPSTREAM_BUG_REPORT.md

3. Independently Verify an Evidence Bundle (CLM-004)

bash
crucible verify --bundle CRUCIBLE-BUG-2026-001.json --replay
